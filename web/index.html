INSTALLATION

Up and running in 30 seconds

Choose your browser family and copy any internal address in one click.

01

Download & Unzip

Download pricelens-firefox-v3.3.zip and extract it to a permanent folder.

02

Open Debugging

Paste this into your address bar and press Enter:

about:debugging#/runtime/this-firefox
03

Load Manifest

Click Load Temporary Add-on... and choose manifest.json inside the extracted folder.

Permanent

Zen / Developer Edition

Set this flag to false in about:config, then install the .zip via about:addons:

xpinstall.signatures.required
01

Download & Unzip

Download pricelens-chromium-v3.3.zip and extract it to a permanent folder.

02

Open Extensions

Paste this into your Chrome, Brave, Edge, or Arc address bar:

chrome://extensions
03

Developer Mode

Toggle Developer mode on in the top-right corner.

04

Load Unpacked

Click Load unpacked, select the extracted folder, and pin PriceLens to your toolbar.

Kiwi / Mises

Direct .zip Install

Open chrome://extensions, enable Developer mode, tap +(from .zip), and pick pricelens-chromium-v3.3.zip.

Firefox Nightly

Install From File

Enable xpinstall.signatures.required = false in about:config and install pricelens-firefox-v3.3.zip.
